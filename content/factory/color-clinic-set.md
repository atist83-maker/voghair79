## 1. 세트 메뉴 구성 (3단계)

| 세트 | 구성 | 가격 | 누구에게 |
|---|---|---|---|
| **컬러 베이직** | 염색 + 컬러 고정 트리트먼트 | [ ]원 | 첫 염색, 건강모 |
| **컬러 케어** ★추천 | 염색 + 클리닉 + OC 샴푸 미니(체험용) | [ ]원 | 염색 자주 하는 분, 색이 금방 빠지는 분 |
| **컬러 프리미엄** | 염색 + 집중 클리닉 + OC 샴푸 정품 | [ ]원 | 탈색모·손상모, 애쉬·베이지처럼 잘 빠지는 컬러 |

가격 잡는 법
- 세트가 = (염색 + 클리닉 + 샴푸) 단품 합계의 약 80~85%. "따로 하면 [ ]원 → 세트 [ ]원"으로 보여 주기
- 가운데(컬러 케어)를 고르게 만드는 게 목표. 프리미엄은 케어가 싸 보이게 하는 기준점
- 기존 혜택(네이버 예약 20%, 첫 방문 염색 30~40%)과 중복 적용 여부는 미리 정해 두기

## 2. 왜 세트인가 (상담 멘트)

> "염색은 시술보다 **2주 동안 관리**가 색을 결정해요. 그래서 클리닉으로 모발을 채우고, 집에서는 OC 샴푸로 이어 가시라고 세트로 묶었어요."

- 시술 중: OC 샴푸로 실제 샴푸해 드리고 "오늘 쓴 샴푸예요" 한마디
- 계산 때: 컬러 케어 세트 고객은 미니 샴푸 전달 → 2주 뒤 재구매로 연결
- 2주 뒤: 카톡 "색 유지 잘 되고 계세요? 사진 보내주시면 봐 드릴게요"

## 4. 릴스 대본 (약 30초)

| 시간 | 화면 문구 | 말 | 촬영할 장면 |
|---|---|---|---|
| 0–3초 | 염색 2주 만에 색 빠지는 분? | 염색 2주 만에 색 빠지시는 분, 이거 보세요. | 염색 3주 뒤에도 색 남은 머리 (결과 먼저) |
| 3–8초 | 색이 빠지는 이유 | 색이 빨리 빠지는 건 모발 속이 비어 있어서예요. | 손상모 끝 클로즈업 |
| 8–15초 | 염색 + 클리닉 | 그래서 염색할 때 클리닉으로 속을 같이 채워요. | 도포 → 클리닉 → 헹굼 (3컷) |
| 15–22초 | 집에서는 OC 샴푸 | 집에서는 순한 OC 샴푸로 색을 지켜 주세요. | OC 샴푸 거품, 손 위에 제품 |
| 22–27초 | 당일 vs 3주 뒤 | 당일이랑 3주 뒤, 차이 보이시죠? | 같은 고객 같은 자리 전후 비교 |
| 27–30초 | 댓글에 '컬러' | 댓글에 '컬러' 남기시면 세트 할인 보내드려요. | 매장 간판 + 엔딩 카드 |
